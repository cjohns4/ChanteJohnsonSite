Hi, I'm Chante' Johnson

Instructional Designer & Learning Experience Designer with 7+ years designing training for government, healthcare, and enterprise teams, backed by 20+ years in IT.

I've trained more than 15,000 learners across two Pennsylvania state agencies, from statewide Microsoft 365 programs to the rollout of a new birth and death registration system for hospitals, clinics, and registrars. I design eLearning, microlearning, and live virtual training that turn complex systems into clear, confident, everyday skills.

My technical background is what sets my work apart. I understand the systems I teach, so the learning I build is accurate, practical, and easy to apply on the job.

Rather than using drag-and-drop site builders, I wrote this site from scratch using HTML and CSS and deployed it via GitHub Pages. It reflects how I build learning experiences: structured, intentional, and tailored from the ground up.
