eVitals Navigator Sample Project

This sample onboarding guide shows how I would design role-based training for a vital records system. I built it with HTML and CSS, and it imagines learning paths for staff in hospitals, nursing homes, funeral homes, coroner offices, and health departments, each organized around the tasks their role needs to complete. The project shows my approach to turning a complex, compliance-heavy system into clear and accessible guidance for first-time and experienced users alike.

Goal: Built to shorten onboarding time for new facility users and reduce data-entry and validation errors.

Role: Instructional Design, Web Development Tools: HTML, CSS, GitHub Pages Deliverable: Role-Based Training Website
